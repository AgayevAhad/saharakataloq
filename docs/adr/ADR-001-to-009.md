# Architecture Decision Records (ADR-001 – ADR-009)
## Sahara Electronics Platform

---

### ADR-001: Kataloqdan Tam Çoxbrendli Elektronika Platformasına Keçid
- **Status:** Təsdiqləndi
- **Kontekst:** Mövcud sistem təkbrendli kataloq kimi başlamış, lakin ARDO, LOTUS, ARTEL və gələcək brendləri (Samsung, Bosch və s.) dəstəkləyən tammiqyaslı elektronika platformasına çevrilməlidir.
- **Qərar:** Kod bazası "brand-agnostic" arxitekturaya keçirilir. Brend məlumatları, rəngləri, kateqoriyaları və texnologiyaları verilənlər bazasından dinamik idarə olunur.
- **Nəticə:** Yeni brend əlavə edildikdə heç bir frontend kod dəyişikliyi tələb olunmur.

---

### ADR-002: İkili SQLite Bazası (Draft/Published) və İmmutable Snapshot Sistemi
- **Status:** Təsdiqləndi
- **Kontekst:** Admin panelində edilən dəyişikliklərin public müştərilərə dərhal təsir etməməsi və səhvlər zamanı təcili geri qayıtma imkanı lazımdır.
- **Qərar:** İki ayrı baza saxlanılır: `catalog-draft.sqlite` və `catalog.sqlite`. Bütün redaktələr qaralamaya yazılır. "Təsdiqlə və Dərc Et" əməliyyatı zamanı avtomatik snapshot arxivi yaradılır və atomik transaction ilə dərc olunur.
- **Nəticə:** Sıfır məlumat itkisi, təhlükəsiz eksperiment və tək kliklə rollback.

---

### ADR-003: 1:1 Pixel-Perfect Skeleton Loading və Pill Naviqasiyası
- **Status:** Təsdiqləndi
- **Kontekst:** Səhifə yüklənərkən tullanmalar (CLS) və kobud sıçrayışlar istifadəçi təcrübəsini pozur.
- **Qərar:** Hər bir komponent üçün real kontentin hündürlüyünə və padding-lərinə 1:1 uyğun gələn `.skeleton-card` və `ShimmerImage` yer tutucuları təyin edilir. Üfüqi kateqoriya pill-ləri seçildikdə mərkəzə yumşaq şəkildə scroll olunur.
- **Nəticə:** CLS < 0.05, 60fps axıcı animasiya və lüks açılış hissi.

---

### ADR-004: Proqressiv Ticarət Modeli (Progressive Commerce)
- **Status:** Təsdiqləndi
- **Kontekst:** Platformanın dərhal tam e-commerce (ödəniş, bank şlüzü) ilə açılması risklidir; bazar mərhələli öyrənilməlidir.
- **Qərar:** 
  1. Mərhələ A: "Əlaqə ilə qiymət/satış" (WhatsApp, birbaşa zəng, filial seçimi).
  2. Mərhələ B: Şəffaf qiymət, taksit kalkulyatoru, mağazada rezervasiya və çatdırılma paketi.
  3. Mərhələ C: Onlayn səbət, kartla ödəniş və şəxsi kabinet.
- **Nəticə:** Biznes risklərinin minimuma endirilməsi və sürətli bazara çıxış.

---

### ADR-005: 1:1 Dəqiq Media Uyğunluğu və Təyin Edilməmiş Fayl Nəzarəti
- **Status:** Təsdiqləndi
- **Kontekst:** Məhsul şəkillərinin kateqoriya və ya təxminlə məhsullara bağlanması səhv fotoşəkillərin müştəriyə göstərilməsinə səbəb ola bilər.
- **Qərar:** Şəkillər və videolar yalnız fayl adında model kodu 1:1 dəqiq uyğun gəldikdə bağlanır. Qalan bütün fayllar "Unattached Media Review Queue"-ya düşür və hesabatda bildirilir.
- **Nəticə:** 100% dəqiq məhsul vizualları və sıfır səhv nümayiş.

---

### ADR-006: Müşahidəolunma (Observability) və PII-siz Analitika Hadisələri
- **Status:** Təsdiqləndi
- **Kontekst:** İstifadəçi davranışlarını izləyərkən şəxsi məlumatların (PII - telefon, ad, ünvan) sızması və qanunvericilik pozuntusu riski var.
- **Qərar:** Bütün analitika hadisələri anonim sessiya ID-si ilə saxlanılır. Telefon nömrələri və adlar analitika cədvəlinə yazılmır; yalnız aqreqasiya edilmiş baxış və klik sayları toplanır.
- **Nəticə:** GDPR/Fərdiləşdirilmiş Məlumatların Qorunması Qanununa tam uyğunluq.

---

### ADR-007: Çoxsaylı Mağaza və Sərgi Salonu Arxitekturası
- **Status:** Təsdiqləndi
- **Kontekst:** Sahara Electronics bir neçə ticarət mərkəzində və filialda fəaliyyət göstərir; tək ünvan bəsi deyil.
- **Qərar:** Limitsiz mağaza CRUD modeli (ad, dəqiq ünvan, nömrələr, xəritə koordinatları, iş saatları, bayram istisnaları) verilənlər bazasında saxlanılır və LocalBusiness Schema ilə Google-a indeksləndirilir.
- **Nəticə:** Filiallar üzrə dəqiq məlumat və xəritə xətalarında belə zəmanətli əlçatanlıq.

---

### ADR-008: Azərbaycan Dilli Fonetik Ağıllı Axtarış Mühərriki
- **Status:** Təsdiqləndi
- **Kontekst:** Müştərilər Azərbaycan hərflərini (ə, ı, ö, ğ, ç, ş) ingilis hərfləri ilə (e, i, o, g, c, s) və ya tireli/tiresiz yaza bilirlər.
- **Qərar:** Normalizasiya mühərriki bütün simvolları fonetik eyniləşdirir, SKU və model kodlarını prioritetləşdirir və həm desktop (8-9 təklif), həm mobil (5 təklif) üçün çoxsütunlu vizual overlay təqdim edir.
- **Nəticə:** Sıfır nəticəli axtarışların 80% azalması və dərhal model tapılması.

---

### ADR-009: Ciddi Git Branch İzolyasiyası (`saharasitedev` / `saharasitemain`)
- **Status:** Təsdiqləndi
- **Kontekst:** Kataloq və sayt kodlarının qarışması stabil versiyaların qırılmasına səbəb ola bilər.
- **Qərar:** 
  - Bütün inkişaf yalnız `saharasitedev` branch-ində aparılır.
  - `saharasitemain` yalnız istifadəçinin xüsusi təsdiqindən sonra release üçün yenilənir.
  - `dev`, `main` və kataloq branch-lərinə toxunmaq qəti qadağandır.
- **Nəticə:** Mütləq kod təhlükəsizliyi və qorunan release xətti.
